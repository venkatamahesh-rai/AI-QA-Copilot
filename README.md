# AI QA Copilot

An AI-assisted quality engineering platform that transforms
user stories into test scenarios, automation-ready test cases,
and structured defect drafts.

## Planned Features

- User story and acceptance criteria analysis
- Test scenario generation
- Positive, negative, and boundary test cases
- Defect draft generation
- Gherkin feature file export
- C# Playwright automation support
- REST API testing
- GitHub Actions CI/CD

## Technology Stack

- C# and ASP.NET Core
- Playwright
- xUnit
- React and TypeScript (planned)
- GitHub Actions

Initial project setup in progress.
